# 🎨 Art TG Autopost

Автопостинг у Telegram-канал або групу: **три публікації щодня о 10:00, 15:00
і 20:00 за київським часом**.
Працює на GitHub Actions — не потребує сервера, ввімкненого комп'ютера чи оплати.

## Що публікується

| Час | Контент | Якщо джерело недоступне |
|-----|---------|--------------------------|
| 10:00 | Свіжі новини артсвіту з українських медіа | цікавий факт |
| 15:00 | Картина / художник дня із зображенням | факт або мем |
| 15:00 (вт, пт) | Знижки на художні матеріали в укр. магазинах | картина дня |
| 20:00 | Мем або жарт про художнє життя | факт |

У банку **111 готових постів** українською (46 фактів, 37 «картина/художник
дня», 28 мемів) — цього вистачає приблизно на місяць без жодного повтору,
навіть якщо всі зовнішні джерела впадуть.

## Фільтр росконтенту

`bot/filters.py` блокує все, що стосується росії: державу, міста, музеї (Ермітаж,
Третьяковка), медіа, домени `.ru`. Фільтр застосовується **двічі** — коли новина
відбирається з фіду і ще раз безпосередньо перед відправкою.

Художники українського походження, яких росія привласнила — **Малевич** (нар.
у Києві), **Куїнджі** (нар. у Маріуполі), **Рєпін** (нар. у Чугуєві),
**Айвазовський** (нар. у Феодосії), **Соня Делоне** (нар. на Полтавщині) —
**не блокуються**. Вони навпаки є в банку контенту з правильним українським
контекстом. Це закріплено тестами: `tests/test_filters.py::TestReclaimedArtists`.

Ім'я художника не є індульгенцією: «Малевич — великий російський художник»
або «Рєпін у Третьяковській галереї» фільтр усе одно зупинить.

## Налаштування (15 хвилин)

### 1. Створіть бота

1. У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумайте назву й username (має закінчуватися на `bot`)
3. BotFather надішле **токен** виду `8123456789:AAH...` — збережіть його

### 2. Додайте бота в групу

1. Група → «Учасники» → «Додати» → знайдіть свого бота
2. Зробіть його **адміністратором** із правом «Публікація повідомлень»
   (без прав адміна бот не зможе постити)

### 3. Дізнайтеся chat_id групи

Напишіть будь-яке повідомлення у групу, потім відкрийте в браузері:

```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
```

Знайдіть `"chat":{"id":-1001234567890`. Це і є `chat_id` — **з мінусом**.

> Якщо у групі увімкнено «Теми» (topics) і пости мають іти в конкретну тему —
> у тій самій відповіді знайдіть `message_thread_id` і збережіть його теж.

### 4. Залийте репозиторій на GitHub

```bash
git init
git add .
git commit -m "Art TG autopost"
git branch -M main
git remote add origin git@github.com:ВАШ_НІК/art-tg-autopost.git
git push -u origin main
```

> Зробіть репозиторій **публічним** — тоді хвилини GitHub Actions безлімітні.
> Токен бота у код не потрапляє, він живе в секретах.

### 5. Додайте секрети

Settings → Secrets and variables → Actions → **New repository secret**:

| Ім'я | Значення |
|------|----------|
| `TELEGRAM_BOT_TOKEN` | токен від BotFather |
| `TELEGRAM_CHAT_ID` | `-100...` вашої групи |
| `TELEGRAM_THREAD_ID` | *(необов'язково)* id теми в групі |

### 6. Перевірте

Actions → «Публікація в Telegram» → **Run workflow**:

- спершу з `dry_run = true` — побачите текст у логах, у групу нічого не піде;
- потім `slot = 15` без dry_run — прийде реальний пост.

Далі все працює само.

## Корисне

```bash
# локальний перегляд без відправки
python -m bot.main --force-slot 20 --dry-run

# перевірити, які RSS та магазини живі
python -m tools.check_sources

# перезібрати банк контенту після редагування
python tools/build_bank.py
```

Діагностика джерел також запускається автоматично щопонеділка
(Actions → «Перевірка джерел») — там видно, що зламалося.

## Структура

```
bot/
  main.py           точка входу: який слот, який тип, надіслати
  config.py         слоти, план контенту, список джерел
  filters.py        фільтр росконтенту
  telegram.py       Bot API
  state.py          що вже опубліковано
  providers/
    news.py         RSS українських культурних медіа
    deals.py        знижки в художніх магазинах
    evergreen.py    банк готових постів
    artwork.py      зображення з Вікіпедії
content/
  evergreen.json    111 постів українською
tools/
  build_bank.py     збирає content/evergreen.json з вихідників
  build_bank_1.py   факти
  build_bank_2.py   меми та картина дня
  check_sources.py  які RSS і магазини живі
  check_bot.py      чи живий бот і чи він адміністратор чату
tests/              юніт-тести фільтра, слотів і банку
state/state.json    що вже опубліковано (комітиться ботом)
```

## Тести

```bash
python -m unittest discover -s tests -t . -v
```

Що перевіряється:

- `tests/test_filters.py` — «Ермітаж», «Москва», «Russian museum», `example.ru`
  блокуються; «Малевич народився у Києві», «Київська Русь», «Рєпін народився
  у Чугуєві», «Виставка в Луврі» — ні;
- `tests/test_slots.py` — о 09:59 нічого; о 10:00 і 12:29 слот 10; о 12:31 слот
  10 тихо закривається без публікації; о 20:10 слот 20;
- `tests/test_bank.py` — у банку ≥100 постів, усі три типи, підписи до фото
  ≤1024 символи, теги HTML валідні для Telegram, дублікатів `id` немає;
- `tests/test_plan.py` — який тип контенту йде в який слот, знижки у вівторок
  і п'ятницю, і головне: падіння будь-якого джерела не зриває публікацію;
- `tests/test_telegram_guard.py` — друга перевірка фільтром прямо перед
  відправкою.

Тести ганяються автоматично при кожному push (workflow «Тести») і перед
кожною публікацією (workflow «Публікація в Telegram»).

## Як змінити під себе

### Додати свій пост

Банк збирається скриптом, а не редагується руками. Відкрийте
`tools/build_bank_1.py` (факти) або `tools/build_bank_2.py` (меми й картина дня)
і додайте кортеж у відповідний список:

```python
# tools/build_bank_1.py — FACTS
("Текст факту українською. Можна <b>жирний</b> та <i>курсив</i>.",
 "#факт #пігменти"),

# tools/build_bank_2.py — MEMES
("Текст мему.", "#мемчик"),

# tools/build_bank_2.py — ARTWORKS: (стаття Вікіпедії, мова, текст, теги)
("Mona_Lisa", "en",
 "🖼 <b>«Мона Ліза»</b> — Леонардо да Вінчі, бл. 1503\n\nКороткий цікавий факт.",
 "#картинадня"),
```

Далі перезберіть банк:

```bash
python tools/build_bank.py
```

Скрипт **відмовиться** зібрати банк, якщо фільтр знайде росконтент, і впаде,
якщо якийсь підпис до фото довший за 1024 символи.

> Зображення до `artwork` **не хардкодяться** — у банку лежить лише назва
> статті Вікіпедії, а файл тягнеться в рантаймі через MediaWiki API. Тому
> посилання не протухають. Якщо `sendPhoto` не спрацював — пост піде текстом.

### Змінити час публікацій

`bot/config.py`:

```python
SLOTS = [10, 15, 20]        # години за київським часом
SLOT_GRACE_MINUTES = 150    # наскільки слот може спізнитись і все ще відпрацювати
```

Крон у `.github/workflows/post.yml` чіпати **не треба**: він навмисно стоїть на
`*/15 * * * *`, а рішення «чи час постити» ухвалює сам скрипт за
`ZoneInfo("Europe/Kyiv")`. Через це перехід на літній/зимовий час не зсуває
розклад на годину. Слот, прострочений більше ніж на `SLOT_GRACE_MINUTES`,
тихо закривається — щоб вечірній пост не прилетів о 3-й ночі.

Що саме йде в який слот — `SLOT_PLAN` у тому ж файлі:

```python
SLOT_PLAN = {
    10: ["news", "fact", "artwork"],   # перший доступний тип і виграє
    15: ["artwork", "fact", "meme"],
    20: ["meme", "fact", "artwork"],
}
DEALS_WEEKDAYS = {1, 4}   # вівторок і п'ятниця: о 15:00 спершу шукаємо знижки
```

### Додати джерело новин

`NEWS_SOURCES` у `bot/config.py`:

```python
{"name": "Назва медіа", "site": "https://example.com/",
 "feeds": ["https://example.com/feed/"]},
```

Якщо прямий фід не відповість, бот сам пошукає
`<link rel="alternate" type="application/rss+xml">` на головній сторінці.
Новина потрапляє в добірку, лише якщо в заголовку чи описі є слово зі списку
`ART_KEYWORDS`, вона не старша за 5 днів і її URL ще не публікувався.

Магазин знижок додається так само — `DEALS_SOURCES`:

```python
{"name": "Магазин", "url": "https://shop.ua/ua/sale/", "home": "https://shop.ua/"},
```

Парсер навмисно «широкий»: шукає блоки зі старою й новою ціною або зі знаком
`-XX%`. Магазин недоступний або змінив верстку → його просто пропускаємо.

### Додати слово в чорний список

`BLOCK_PATTERNS` у `bot/filters.py` — це список **regex-патернів**, які
шукаються в тексті, зведеному до нижнього регістру:

```python
BLOCK_PATTERNS = [
    ...
    r"\bназва_чого_завгодно",   # \b — межа слова, щоб не ловити середину слів
    r"\.xx\b",                  # домен
]
```

Якщо нове слово випадково ловить щось українське (наприклад, `\bказан` зачепив
би «казан»), додайте виняток у `ALLOW_PATTERNS` — ці фрази маскуються ще до
пошуку.

Перевірити свою зміну:

```bash
python -c "from bot.filters import is_blocked, reason; print(is_blocked('текст'), reason('текст'))"
python -m unittest discover -s tests -t . -q
```

Імена з `RECLAIMED_ARTISTS` не можна додавати в чорний список — тест
`test_reclaimed_names_absent_from_block_patterns` це не пропустить.

## Чому не три UTC-крони

Київ узимку UTC+2, улітку UTC+3. Три фіксовані UTC-крони після переходу на
зимовий час постили б о 9:00, 14:00 і 19:00. Тому раннер прокидається кожні
15 хвилин, а слот визначає скрипт за київським часом. `concurrency:
telegram-post` у воркфлоу гарантує, що два запуски не запостять одночасно.
